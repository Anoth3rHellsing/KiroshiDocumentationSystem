## 2025-05-24 - Streamlit Logging Initialization Overhead
**Learning:** Streamlit re-executes the entire script on every interaction. If logging initialization (finding a writable log directory, opening the file, creating handlers) is done at the top level without caching, it incurs significant I/O overhead (multiple syscalls, file opening) on every single user action.
**Action:** Encapsulated logging setup in a `_configure_logging` function decorated with `@st.cache_resource`. This ensures the setup runs only once per session, returning the cached log path. This pattern should be applied to any expensive top-level initialization logic.
