## 2025-05-18 - [Empty State Engagement]
**Learning:** Users often feel lost when confronted with blank dashboards ("No cases found"). Replacing standard `st.info` notifications with visually rich, icon-driven empty states that include "Why" (Keep work visible) and "How" (Go to Tracking tab) transforms a dead-end into an onboarding opportunity.
**Action:** Audit all list/dashboard views for generic "No items" messages and upgrade them to actionable, illustrated components that guide the user to the next step.
