# Kiroshi Desktop Experimental Rebuild

This directory hosts the experimental desktop version of the Kiroshi application.
It is currently under active development in the `codex/experimental-desktop-rebuild`
branch and is intentionally kept separate from the existing Streamlit codebase.

## Structure

- `main.py`: Entry point for the desktop application prototype.
- `ui/`: Components and resources for the graphical user interface.
- `core/`: Core application logic and domain models.
- `assets/`: Static assets such as icons, fonts, and templates.
- `tests/`: Automated tests for the desktop application modules.

## Environment Setup

Install the dependencies listed in the top-level `requirements.txt` to ensure
that the desktop environment is ready for development.
