# Dell Escalation Email Template (Second-Line Mode)

Use this template when all software solutions have been exhausted and ePSA tests have been performed. A reimage is recommended before escalating to Dell.

> **Important:** Contact information must be confirmed directly with the customer before sending. Do **not** automatically pull address or phone details from Kiroshi.

```
Hello Dell Support team,

The end-user from {company_name} has been reporting {issue_description}, which has been happening since {issue_start_date}. Could you please assist this customer with a Dell Technician on site?
Case ID {case_id}
PC service tag {service_tag}
Evidence attached to this email.

Computer information:

- Type of PC
- BIOS Version
- Windows Version
- Dell Command Updates
- Power Options setup
- Dell Optimizer setup
- Intel Processor Power Management Utility installed?
- CPU Speed / Is CPU throttling?
- GPU Usage % (Integrated)
- GPU Usage % (Dedicated)
- CPU Utilization %
- Benchmark used and results
- Can it launch simulation on Ultra Resolution? (If needed)
- Which GPU driver versions were tested?
- Reliability Monitor and Event Viewer results
- Dell Diagnosis test results (ePSA tests included)
- Has Windows been reimaged?

Clinic's contact information:

- Address 1
- Address 2 (Suite, etc.)
- City
- State
- Zip Code
- Full name of person responsible for receiving the equipment
- Phone number
- Email address
- Clinic name

Thank you in advance,
```

Ensure all applicable details are filled in before sending the email.
